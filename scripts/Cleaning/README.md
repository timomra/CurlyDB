# Data Cleaning Scripts



1.  ``data_checks_group13SOP.R``  Runs the initial quality checks.
2. `Clean_Names.R`  calls the previous script, and uses it to clean the data.
3. `impc_csv_cleaning/01_data_cleaning_structural_validation.R` Imports and validates Group 13 CSV files, identifies and repairs structural errors in memory, and combines records into a single data frame. Additionally, flags duplicate and conflicting analyses for further investigation.
